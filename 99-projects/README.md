## 프로젝트 문서 작성 방법

프로젝트마다 `번호-프로젝트명.md` 파일을 하나 만들고 아래 내용을 적는다.

- 저장소 URL, 목적, 주요 디렉토리 구조
- 연결된 학습 노트 목록 (예: `02-evals/03-golden-set`)
- 평가셋 위치와 버전 (질문 수, 생성일)

학습 노트에서는 가능하면 이 문서를 거쳐 코드로 연결한다. 저장소 이름이나 위치가 바뀌면 이 문서만 고치면 된다.
