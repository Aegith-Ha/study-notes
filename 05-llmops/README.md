# 05-llmops

운영(LLMOps) (4순위)

트레이싱, 비용, 보안, 피드백 루프 등 운영에 필요한 요소를 다룬다.

## Topics

| Topic | 내용 | 상태 |
| --- | --- | --- |
| 01-tracing | 요청 단위 트레이싱 (Langfuse, Phoenix 등) | 예정 |
| 02-cost-optimization | 프롬프트 캐싱, 시맨틱 캐시, 작은 모델 라우팅으로 비용 최적화 | 예정 |
| 03-security | 프롬프트 인젝션(간접 인젝션 포함), 문서 권한 제어, PII 처리 | 예정 |
| 04-feedback-loop | 사용자 피드백 → 평가셋 → 개선으로 이어지는 루프 | 예정 |

노트 작성 방식은 루트 [README](../README.md)의 작성 규칙 참고.
