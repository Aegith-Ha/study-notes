# 마스크 언어 모델(MLM) vs 자기회귀 언어 모델(AR)

## 1. 핵심 비교

| 구분 | 마스크 언어 모델 (MLM) | 자기회귀 언어 모델 (AR) |
|---|---|---|
| 영어 | Masked Language Model | Autoregressive Language Model |
| 대표 모델 | BERT | GPT |
| 핵심 방식 | 가려진 토큰을 예측 | 다음 토큰을 예측 |
| 문맥 활용 | 앞 + 뒤 문맥 | 이전 토큰들 |
| 주요 강점 | 텍스트 이해/표현 | 텍스트 생성 |
| 대표 활용 | 분류, 검색, 임베딩, Reranker | 챗봇, 글 생성, 코드 생성, 추론 |

---

## 2. 마스크 언어 모델 (MLM)

문장의 일부를 가리고, 주변 문맥을 이용하여 가려진 부분을 예측한다.

예:

나는 오늘 [MASK]에서 밥을 먹었다.

주변의 앞뒤 문맥을 보고 `[MASK]`에 들어갈 단어를 예측한다.

예:

나는 오늘 **식당**에서 밥을 먹었다.

### 특징

- 문장의 앞과 뒤를 함께 볼 수 있다.
- 문장의 의미를 이해하고 표현하는 작업에 강하다.
- 대표적인 모델은 BERT이다.

### 주요 활용

- 문서 분류
- 감성 분석
- 개체명 인식
- 검색
- 임베딩
- Reranker

> 단, 현대의 Encoder/Embedding 모델이 모두 MLM 방식으로만 학습되는 것은 아니다.
> MLM 외에도 대조학습(Contrastive Learning) 등 다양한 학습 방법이 사용된다.

---

## 3. 자기회귀 언어 모델 (AR)

이전에 등장한 토큰들을 이용하여 **다음 토큰을 예측**한다.

예:

나는 → 오늘 → 점심으로 → 김치찌개를 → 먹었다

생성 과정:

나는
↓
나는 오늘
↓
나는 오늘 점심으로
↓
나는 오늘 점심으로 김치찌개를
↓
나는 오늘 점심으로 김치찌개를 먹었다

즉,

**이전에 생성한 토큰들 → 다음 토큰 예측**

과정을 반복하면서 문장을 생성한다.

### 왜 '자기회귀'인가?

자기회귀(Autoregressive)는

- Auto = 자기 자신
- Regressive = 이전 값에 의존

이라는 의미를 가진다.

즉, **자기 자신의 이전 값들을 이용하여 다음 값을 예측하는 방식**이다.

언어 모델에서는 이전에 생성된 토큰들을 이용하여 다음 토큰을 예측한다.

P(x_t | x_1, x_2, ..., x_{t-1})

### 특징

- 이전 토큰들을 보고 다음 토큰을 생성한다.
- 긴 문장을 연속적으로 생성할 수 있다.
- 대표적인 모델은 GPT이다.
- 기본적인 생성 과정에서는 이미 생성한 토큰으로 돌아가 수정하지 않는다.

단, LLM 시스템에서 별도의 검토, 재생성, 추론 등의 과정을 추가하여 결과를 다시 생성하는 것은 가능하다.

---

## 4. 현재의 주요 사용 방식

### MLM / BERT 계열

주로 **텍스트를 이해하고 표현하는 작업**에서 사용된다.

예:

질문
↓
Embedding
↓
Vector Search
↓
Reranker

검색, 임베딩, 문서 분류 등의 영역에서 Encoder 계열 모델이 많이 사용된다.

### AR / GPT 계열

주로 **새로운 내용을 생성하는 작업**에서 사용된다.

예:

사용자 질문
↓
LLM
↓
다음 토큰 예측
↓
다음 토큰 예측
↓
...
↓
최종 답변

ChatGPT 같은 현대 생성형 LLM의 핵심 방식이다.

---

## 5. 한 줄 정리

**마스크 언어 모델(MLM)**  
→ `빈칸 맞히기`  
→ 문장을 **이해하고 표현하는 데 강함**

**자기회귀 언어 모델(AR)**  
→ `다음 토큰 맞히기`  
→ 문장을 **생성하는 데 강함**

현재는 생성형 AI의 중심이 자기회귀 모델이며,
마스크 언어 모델과 Encoder 계열은 검색, 임베딩, 분류, Reranking 등의 영역에서 여전히 중요하게 사용된다.
