# Foundation Model vs LLM vs LMM

## 한눈에 비교

| 용어 | 기준 | 의미 |
|---|---|---|
| Foundation Model | 역할 / 범용성 | 여러 작업의 기반이 되는 대규모 사전학습 모델 |
| LLM | 데이터 / 능력 | 언어를 중심으로 다루는 대규모 모델 |
| LMM | 모달리티 | 텍스트, 이미지, 음성 등 여러 형태의 데이터를 다루는 대규모 모델 |

---

## 1. Foundation Model

**여러 작업의 기반(Foundation)이 되는 범용 사전학습 모델**

- 대규모 데이터로 미리 학습
- 하나의 특정 작업만을 위한 모델이 아님
- 번역, 요약, 질의응답, 생성 등 다양한 작업에 활용 가능
- 꼭 언어 모델일 필요는 없음

> 핵심: **"여러 작업의 기반이 되는가?"**

---

## 2. LLM (Large Language Model)

**대규모 언어 모델**

- 텍스트/언어를 중심으로 학습
- 질문 답변, 요약, 번역, 글쓰기, 코드 생성 등에 사용

> 핵심: **"언어(Language)를 다루는가?"**

---

## 3. LMM (Large Multimodal Model)

**대규모 멀티모달 모델**

- 여러 종류의 데이터를 함께 처리
- 텍스트 + 이미지 + 음성 + 영상 등

예:

텍스트 ─┐
이미지 ─┼→ LMM → 이해 / 추론 / 생성
음성   ─┤
영상   ─┘

> 핵심: **"여러 모달리티(Multimodal)를 다루는가?"**

---

## GPT는?

현대의 멀티모달 GPT 모델은 세 가지에 동시에 해당할 수 있다.

- **Foundation Model** → 다양한 작업의 기반이 됨
- **LLM** → 대규모 언어 능력을 가짐
- **LMM** → 이미지, 음성 등 여러 모달리티를 처리

즉,

**현대 GPT = Foundation Model + LLM + LMM**

단, GPT-2 같은 과거의 텍스트 전용 모델은
**Foundation Model + LLM**이지만 LMM은 아니다.

---

## 핵심 정리

- **Foundation Model** → 여러 작업의 **기반인가?**
- **LLM** → **언어**를 다루는가?
- **LMM** → **여러 형태의 데이터**를 다루는가?

Foundation Model과 LLM/LMM은 완전히 같은 기준의 분류가 아니다.
