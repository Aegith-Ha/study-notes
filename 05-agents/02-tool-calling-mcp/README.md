# 도구 호출과 MCP (Tool Calling, MCP)

LLM이 함수(도구)를 골라 호출하게 하는 function calling과, 도구를 여러 앱에 표준 방식으로 연결하는 MCP를 정리한다. 사내 DB·API를 에이전트에 안전하게 연결하는 것이 목표다. 이 README에는 메인 결정과 결과를 두고, 원리와 설계 원칙은 하위 노트에 둔다.

- 검색을 도구로 쓰는 Agentic RAG는 [01-agentic-rag](../01-agentic-rag/README.md) 참고

## 하위 노트

- [01-function-calling](./01-function-calling.md): 동작 흐름, 도구 정의(이름, 설명, 스키마), 설계 원칙, 평가 지표와 손계산 예시
- [02-mcp](./02-mcp.md): 표준이 필요한 이유, 구성 요소(호스트, 클라이언트, 서버, tools·resources·prompts), 사내 DB·API 연결 원칙, 보안 위험

## 메인 결정 (초안)

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 첫 도구 | 읽기 전용: `search_law`, `get_article` (조문 원문 조회) | 위험이 없고 평가가 쉬움 |
| 도구 설계 | 목적별 도구, enum 허용값, 언제 쓰지 않는지까지 설명 | 선택·인자 오류 감소 |
| 쓰기 도구 | 별도 서버, 사람 확인 후 실행 | 실수·인젝션 피해 차단 |
| 사내 DB | 자유 SQL 금지, 읽기 전용 계정, 사용자 권한 전달, 감사 기록 | 권한 밖 조회 방지 |
| 연결 방식 | 도구를 MCP 서버로 제공 | 채팅 앱, 자체 에이전트에서 재사용 |
| 평가 | 도구 호출 평가 세트(요청 + 정답 도구 + 정답 인자)로 선택 정확도, 인자 일치, 스키마 위반, 불필요 호출 | 정답이 분명해 judge 없이 채점 |
