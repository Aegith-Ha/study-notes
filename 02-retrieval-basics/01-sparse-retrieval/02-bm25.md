# BM25와 변형 (BM25, BM25+, BM25L, BM25F)

TF-IDF의 두 문제(tf가 끝없이 커짐, 문서 길이 무시)를 고친 BM25와 그 변형을 정리한다. BM25는 sparse 검색의 사실상 표준이고, 이 저장소의 모든 검색 비교에서 첫 번째 기준선이다.

- 폴더 요약, 메인 결정, 결과는 [README](./README.md) 참고
- 역색인과 TF-IDF는 [01-inverted-index-tfidf](./01-inverted-index-tfidf.md) 참고

## 1. 공식

```text
score(q, d) = Σ_{t ∈ q} idf(t) × tf(t, d) × (k1 + 1) / ( tf(t, d) + k1 × (1 − b + b × |d| / avgdl) )

idf(t) = ln( 1 + (N − df(t) + 0.5) / (df(t) + 0.5) )      (Lucene 방식, 항상 양수)
```

| 기호 | 의미 | 기본값 |
| --- | --- | --- |
| k1 | tf 포화 정도. 클수록 tf를 더 오래 반영 | 1.2 (보통 1.2~2.0) |
| b | 문서 길이 정규화 강도. 0이면 길이 무시, 1이면 완전 정규화 | 0.75 |
| \|d\| | 문서 길이 (토큰 수) | - |
| avgdl | 전체 문서 평균 길이 | - |

두 가지 개선
- **tf 포화**: tf가 커져도 점수가 `(k1 + 1)`에 가까워질 뿐 끝없이 커지지 않는다.
- **길이 정규화**: 평균보다 긴 문서는 tf의 효과를 줄이고, 짧은 문서는 키운다.

## 2. 손계산 예시

[01-inverted-index-tfidf](./01-inverted-index-tfidf.md)와 같은 문서, 같은 질의 `재설정 링크`

```text
N = 4, 문서 길이: d1 = 4, d2 = 6, d3 = 4, d4 = 2 → avgdl = 4
k1 = 1.2, b = 0.75

idf(재설정) = ln(1 + (4 − 2 + 0.5) / (2 + 0.5)) = ln(2.0)   = 0.693
idf(링크)   = ln(1 + (4 − 3 + 0.5) / (3 + 0.5)) = ln(1.429) = 0.357
```

길이 정규화 항 `k1 × (1 − b + b × |d| / avgdl)`

| 문서 | \|d\| | 정규화 항 |
| --- | --- | --- |
| d1, d3 | 4 | 1.2 × (0.25 + 0.75 × 1.0) = 1.20 |
| d2 | 6 | 1.2 × (0.25 + 0.75 × 1.5) = 1.65 |
| d4 | 2 | 1.2 × (0.25 + 0.75 × 0.5) = 0.75 |

| 문서 | 재설정 tf 항 | 링크 tf 항 | BM25 점수 | BM25 순위 | TF-IDF 순위 |
| --- | --- | --- | --- | --- | --- |
| d1 | 1 × 2.2 / (1 + 1.20) = 1.000 | 1.000 | 0.693 + 0.357 = **1.050** | **1** | 2 |
| d2 | 2 × 2.2 / (2 + 1.65) = 1.205 | - | 0.693 × 1.205 = 0.836 | 2 | 1 |
| d4 | - | 1 × 2.2 / (1 + 0.75) = 1.257 | 0.357 × 1.257 = 0.448 | 3 | 3 (동점) |
| d3 | - | 1.000 | 0.357 | 4 | 3 (동점) |

읽는 법
- **tf 포화**: d2의 `재설정` tf는 2지만 tf 항은 1.205다. 두 배가 되지 않는다. 그래서 질의 두 단어를 모두 가진 d1이 1위로 올라온다.
- **길이 정규화**: d3과 d4는 `링크`를 한 번씩 가졌지만, 짧은 d4(2단어)의 tf 항이 1.257로 더 크다. TF-IDF에서는 동점이었다.

## 3. 파라미터 조정

| 상황 | 조정 방향 |
| --- | --- |
| 같은 단어 반복이 실제로 중요함 (긴 설명 문서) | k1을 올린다 |
| 문서 길이가 고르게 비슷함 (조문 단위 청크) | b의 영향이 작다. 기본값 유지 |
| 긴 문서가 부당하게 밀림 | b를 낮춘다 |
| 짧은 제목·FAQ가 지나치게 위로 옴 | b를 올리거나 필드별로 나눈다 (BM25F) |

- 파라미터는 골든셋 **dev 세트**에서만 조정한다. test 세트로 조정하면 기준선이 부풀려진다([03-update-loop](../../03-evals/03-golden-set/03-update-loop.md) 5장).
- 조정 전후를 같은 표에 남긴다. 기본값(k1 = 1.2, b = 0.75)도 하나의 기준선이다.

## 4. 변형

| 변형 | 고친 문제 | 핵심 아이디어 | 쓰면 좋은 곳 |
| --- | --- | --- | --- |
| BM25+ | 아주 긴 문서에서 질의 단어가 나와도 tf 항이 0에 가까워짐 | tf 항에 작은 하한 δ를 더함 | 문서 길이 차이가 매우 큰 경우 |
| BM25L | 긴 문서가 지나치게 불리함 | 길이로 나눈 tf에 상수를 더해 긴 문서 보정 | 긴 문서가 정답인 경우가 많을 때 |
| BM25F | 제목, 본문 등 필드 구분 없음 | 필드마다 가중치와 길이 정규화를 따로 적용 | 법령명·조문 제목·본문처럼 필드가 있는 문서 |

- 법령 데이터는 법령명, 조문 제목, 본문이 나뉘어 있어 BM25F를 시도해 볼 만하다. 다만 먼저 기본 BM25 기준선을 잡은 뒤 비교한다.

## 5. 확인할 점

- 라이브러리마다 idf 공식과 기본값이 조금씩 다르다(예: idf에 `1 +`를 더하는지). 라이브러리 이름과 버전을 실험 조건에 기록한다.
- 직접 구현했다면 이 노트의 손계산 예시를 단위 테스트로 쓴다([05-regression-ci](../../03-evals/05-regression-ci/01-gate-design.md) L0).
