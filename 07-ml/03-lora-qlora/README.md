# LoRA와 QLoRA (LoRA, QLoRA)

큰 언어 모델의 일부 파라미터만 학습하는 LoRA와, 기반 모델을 4-bit로 줄여 적은 GPU 메모리로 학습하는 QLoRA를 정리한다. 언제 파인튜닝이 맞고 언제 RAG·프롬프트가 맞는지도 함께 판단한다. 이 README에는 메인 결정과 결과를 두고, 원리와 계산은 하위 노트에 둔다.

- 메모리 계산 기초는 [01-pytorch-hf/01-pytorch-basics](../01-pytorch-hf/01-pytorch-basics.md) 참고

## 하위 노트

- [01-lora](./01-lora.md): 저랭크 분해 원리, 학습 파라미터 수 손계산, 하이퍼파라미터(r, alpha, 대상 층), 병합과 어댑터 교체
- [02-qlora-and-when](./02-qlora-and-when.md): 4-bit 양자화(NF4), 메모리 손계산, 파인튜닝 vs RAG vs 프롬프트 판단, 평가 방법

## 메인 결정 (초안)

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 목적 | 답변 형식·거절·인용 방식 같은 **행동** 학습 | 법령 지식은 개정되므로 RAG로 공급 |
| 하지 않는 것 | 법령 내용을 외우게 하는 학습 | 개정 시 재학습 필요, 근거 없는 답 증가 위험 |
| 방법 | QLoRA (4-bit 기반 모델 + LoRA) | 24 GB GPU 한 장에서 7~8B 학습 |
| 시작 설정 | r = 16, alpha = 32, 어텐션·MLP 투영 층 전체 | 흔한 시작점, 결과로 조정 |
| 데이터 | (질문, 검색 문서, 모범 답변) — 답변은 문서 근거만 사용 | RAG 환경과 같은 입력으로 학습 |
| 비교 기준 | 같은 기반 모델 + 프롬프트만 개선한 결과 | 파인튜닝이 프롬프트보다 나은지 먼저 확인 |
| 평가 | 골든셋 생성 지표 + 형식 준수율 + 일반 능력 저하 확인 | 목적 지표와 부작용 함께 |
