# QLoRA와 적용 판단 (QLoRA, When to Fine-tune)

기반 모델을 4-bit로 양자화해 LoRA 학습 메모리를 더 줄이는 QLoRA와, 파인튜닝을 할지 RAG·프롬프트로 해결할지 판단하는 기준, 평가 방법을 정리한다.

- 폴더 요약과 기본 선택은 [README](./README.md) 참고
- LoRA 원리는 [01-lora](./01-lora.md) 참고

## 1. QLoRA 구성

| 요소 | 내용 |
| --- | --- |
| 4-bit NF4 | 가중치 분포(정규분포에 가까움)에 맞춘 4-bit 형식으로 기반 모델 저장 |
| double quantization | 양자화에 쓰는 배율 값까지 다시 양자화해 추가 절약 |
| 계산 dtype | 계산할 때는 bf16으로 풀어서 연산 |
| LoRA | 어댑터는 bf16으로 학습 (기반 모델은 고정) |
| paged optimizer | 메모리가 순간적으로 넘칠 때 CPU 메모리로 넘김 |

## 2. 손계산 예시: 7B 학습 메모리

| 방식 | 기반 모델 | 학습 상태 | 합계 (활성값 제외) |
| --- | --- | --- | --- |
| 전체 파인튜닝 | 7B × 16 바이트에 포함 | | 약 112 GB |
| LoRA (bf16 기반) | 7B × 2 = 14 GB | 약 0.27 GB | 약 14.3 GB |
| QLoRA (4-bit 기반) | 7B × 0.5 = 3.5 GB | 약 0.27 GB | 약 3.8 GB |

- 학습 상태 0.27 GB는 [01-lora](./01-lora.md)의 16.8M 파라미터 가정이다. 실제로는 활성값(배치 × 길이)이 몇 GB 더 든다. RAG 입력은 검색 문서 때문에 길어서 활성값이 크다.
- QLoRA는 메모리를 줄이는 대신 학습이 느려지고(양자화 풀기), LoRA(bf16)보다 품질이 약간 낮을 수 있다. 함께 비교한다.

## 3. 파인튜닝할까, RAG·프롬프트로 할까

| 하고 싶은 것 | 맞는 방법 | 이유 |
| --- | --- | --- |
| 최신 문서 내용으로 답하기 | RAG | 개정되면 문서만 바꿈, 근거 제시 가능 |
| 답변 형식 고정 (문서 인용 형식, 구조) | 프롬프트 → 부족하면 파인튜닝 | 프롬프트로 대부분 해결 |
| 근거 없으면 거절하는 행동 | 프롬프트 + 파인튜닝 | 작은 모델은 프롬프트만으로 잘 안 지킴 |
| 도메인 문체, 용어 사용 | 파인튜닝 | 예시로 배우는 것이 효과적 |
| 작은 모델로 큰 모델 수준 | 파인튜닝 (큰 모델 답변으로 학습) | 비용 절감 ([06-llmops/02-cost-optimization](../../06-llmops/02-cost-optimization/02-model-routing.md)) |

- 순서: 프롬프트 개선 → RAG 개선 → 그래도 남는 행동 문제에 파인튜닝.
- 지식을 외우게 하는 파인튜닝은 근거 없는 답(환각)을 늘릴 수 있다. 모델이 문서에 없는 내용을 "기억"으로 말하기 때문이다.
- 큰 모델 답변으로 학습할 때는 그 모델의 이용 약관을 확인한다.

## 4. 평가

| 확인 | 지표 | 위치 |
| --- | --- | --- |
| 목적 달성 | Answer Correctness, Faithfulness, 거절 정확도 | [03-evals/02-generation-metrics](../../03-evals/02-generation-metrics/README.md) |
| 형식 | 형식 준수율 (규칙으로 채점) | 별도 채점 |
| 부작용 | 일반 능력 세트 점수, 문서 밖 내용 증가 여부 | 일반 능력 평가 세트 |
| 검색 결과 변화에 대한 견고성 | 검색 실패 문항에서 거절하는가 | 골든셋 4분면 |

- 학습 데이터의 모범 답변을 judge로 만들었다면, 같은 judge로 평가하면 점수가 부풀 수 있다. 평가 judge는 다른 모델로 두거나 사람 표본으로 확인한다([03-evals/04-llm-judge](../../03-evals/04-llm-judge/README.md)).

## 5. 확인할 점

- 기반 모델 라이선스가 파생 모델 배포를 허용하는지 확인한다.
- 학습 데이터에 골든셋 질문·문서 조합이 들어가지 않게 한다([02-embedding-finetuning/01-training-data](../02-embedding-finetuning/01-training-data.md) 3장과 같은 원칙).
