# 긴 컨텍스트 vs RAG 실험 설계 (Experiment Design)

검색 없이 문서를 통째로 긴 컨텍스트에 넣는 방식과 RAG를 공정하게 비교하는 실험 설계를 정리한다. "컨텍스트 창이 커졌는데 RAG가 아직 필요한가"에 데이터로 답하는 것이 목적이다.

- 폴더 요약과 기본 선택은 [README](./README.md) 참고
- 비용과 지연 계산은 [02-cost-latency](./02-cost-latency.md) 참고

## 1. 비교할 설정

| 설정 | 컨텍스트에 넣는 것 | 컨텍스트 크기 (예) |
| --- | --- | --- |
| R. RAG | 검색 top-5 섹션 | 약 2천 토큰 |
| L. 긴 컨텍스트 (문서 통째) | 질문과 관련된 문서 전체 | 수만 토큰 |
| RL. RAG + 긴 컨텍스트 | 검색 top-50 섹션 | 약 2만 토큰 |
| O. oracle | 골든셋 정답 근거 섹션 | 약 1천 토큰 |

- 전체 문서 집합(문서 수천 개)은 어떤 컨텍스트 창에도 들어가지 않는다. 그래서 L은 **어느 문서를 넣을지 먼저 정해야** 한다. 이 선택 자체가 일종의 검색이다.
- L에서 문서 선택은 두 가지로 나눠 본다.
  - L-oracle: 정답 섹션이 속한 문서를 넣음 (긴 컨텍스트의 상한)
  - L-검색: 문서 단위 검색으로 고른 문서를 넣음 (현실적인 성능)
- O는 생성의 상한이다. 모든 설정은 O와의 차이로도 본다.

## 2. 고정할 것과 바꿀 것

| 고정 | 바꿈 |
| --- | --- |
| 생성 모델·버전, temperature 0 | 컨텍스트 구성 (R / L / RL / O) |
| 프롬프트 규칙 (자료만 사용, 거절 문구, 인용) | |
| 골든셋 질문, judge | |

- 생성 모델은 긴 컨텍스트를 지원하는 같은 모델로 모든 설정을 돌린다. 모델이 다르면 컨텍스트 방식의 차이와 모델 차이가 섞인다.

## 3. 측정

| 구분 | 지표 | 출처 |
| --- | --- | --- |
| 정확도 | Answer Correctness, Claim Recall, 거절 정확도 | [02-generation-metrics](../../03-evals/02-generation-metrics/README.md) |
| 충실도 | Faithfulness, Citation Support | 같은 곳 |
| 비용 | 질의당 입력·출력 토큰, 질의당 비용 | [02-cost-latency](./02-cost-latency.md) |
| 지연 | 첫 토큰까지 시간, 전체 응답 시간 (p50, p95) | 같은 곳 |

- 긴 컨텍스트에서는 인용 채점이 특히 중요하다. 컨텍스트 안의 다른 섹션을 근거로 잘못 인용하는 경우가 늘 수 있다.

## 4. 위치 실험 (lost in the middle)

긴 컨텍스트 안에서 정답 섹션의 위치에 따라 정확도가 달라지는지 본다.

```text
같은 질문, 같은 문서 전체 컨텍스트에서 정답 섹션을 옮겨 가며:
  앞부분 (0~10%)  /  가운데 (45~55%)  /  뒷부분 (90~100%)
→ 위치별 Answer Correctness 비교
```

- 가운데 위치에서 정확도가 떨어지면, 긴 컨텍스트 방식은 "문서를 넣기만 하면 된다"가 아니다. 순서를 정하는 단계(사실상 검색·리랭킹)가 여전히 필요하다.
- 문서 원래 순서를 바꾸면 섹션 간 참조("3.1에도 불구하고")가 어색해질 수 있다. 정답 섹션과 그 하위 항목을 함께 옮긴다.

## 5. 결과 해석

| 결과 | 해석 |
| --- | --- |
| L-oracle ≈ O, L-검색 < R | 긴 컨텍스트의 문제는 "어느 문서를 넣나"(검색)다 |
| L-oracle < O | 모델이 긴 컨텍스트에서 정답을 덜 활용한다 (위치 실험으로 확인) |
| RL > R | top-5가 정답을 놓치는 경우를 더 넓은 컨텍스트가 메움. 비용 대비 판단 |
| R ≈ RL ≈ L, 비용 R ≪ L | RAG 유지 |

- 정확도만이 아니라 **정확도 1%p당 추가 비용**으로 판단한다.

## 6. 확인할 점

- 문서 하나가 컨텍스트 창을 넘는 경우가 있다. 이런 문서에 속한 질문은 L에서 제외하고, 제외한 수를 기록한다.
- 결과는 시점의 모델에 묶인다. 모델이 바뀌면 다시 잰다. 실험 날짜와 모델 버전을 결과에 남긴다.
