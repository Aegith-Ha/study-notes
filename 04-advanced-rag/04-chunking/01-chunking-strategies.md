# 청킹 방법 (Chunking Strategies)

문서를 검색 단위(청크)로 나누는 방법과 크기의 영향을 정리한다. 기본 RAG 실패 유형 중 F6(본문과 예외 문장이 다른 청크로 나뉨)을 고친다.

- 폴더 요약과 메인 결정은 [README](./README.md) 참고
- 작게 찾고 크게 넘기는 방법은 [02-parent-child-contextual](./02-parent-child-contextual.md) 참고

## 1. 청크 크기의 영향

| 청크 | 검색 | 생성 |
| --- | --- | --- |
| 작음 (예: 항 하나) | 내용이 한 가지라 벡터가 선명함, 정확히 찾음 | 조건·예외가 다른 청크에 있어 답이 불완전 |
| 큼 (예: 장 전체) | 여러 내용이 섞여 벡터가 흐려짐, 덜 찾음 | 맥락은 풍부하지만 잡음이 많고 토큰 비용 큼 |

- 검색에 좋은 크기와 생성에 좋은 크기가 다르다. 이 충돌을 푸는 방법이 부모-자식 청크다([02-parent-child-contextual](./02-parent-child-contextual.md)).

## 2. 방법

| 방법 | 나누는 기준 | 장점 | 단점 |
| --- | --- | --- | --- |
| 고정 길이 + 겹침 | N 토큰마다, 앞뒤 일부 겹침 | 단순, 어떤 문서에도 적용 | 문장·조항 중간에서 잘림 |
| 문장·문단 기준 | 문장 끝, 빈 줄 | 문장이 안 잘림 | 길이가 들쭉날쭉 |
| **문서 구조 기준** | 문서의 장 > 절 > 섹션 > 하위 항목 | 의미 단위가 그대로 유지 | 구조 파싱이 필요 |
| 의미 기준 (semantic) | 인접 문장 임베딩 유사도가 떨어지는 곳 | 주제가 바뀌는 곳에서 나눔 | 계산 비용, 결과가 불안정할 수 있음 |

### 고정 길이 손계산

```text
문서 1,000 토큰, 청크 300 토큰, 겹침 50 토큰 → 간격 250 토큰
청크 시작 위치: 0, 250, 500, 750 → 4개 (마지막 청크는 750~1,000, 250 토큰)
저장 토큰 합: 300 + 300 + 300 + 250 = 1,150 → 원문 대비 15% 증가
```

- 겹침은 경계에서 잘린 문장을 양쪽 청크에 남겨 주지만, 저장량과 중복 검색 결과가 늘어난다.

## 3. 구조가 있는 문서의 구조 기준 청킹

```text
3. 환불 정책                                  ← 섹션
  3.1 환불은 결제일로부터 7일 이내에 ...        ← 하위 항목
  3.2 사용 이력이 있는 상품은 환불하지 않는다.
      단, 제품 결함인 경우에는 예외로 한다.     ← 예외 문장
```

| 단위 | 장점 | 단점 |
| --- | --- | --- |
| 섹션 | 예외 문장이 같은 청크에 남음, 골든셋 판정 단위와 같음 | 긴 섹션은 임베딩 최대 길이를 넘음 |
| 하위 항목 | 검색이 정밀 | 예외와 본문이 다른 항목이면 분리됨, 섹션 제목 맥락 손실 |

- 기본은 **섹션 단위**로 하고, 최대 길이를 넘는 섹션만 하위 항목 단위로 나눈다. 나눌 때 각 청크 앞에 `문서 제목 > 3. 환불 정책`을 붙여 맥락을 남긴다.
- 예외 문장("단, …")은 앞 문장과 떼지 않는다.

## 4. 평가할 때 주의

- 청크를 바꾸면 검색 결과의 단위가 바뀐다. 문서 단위로 매핑해서 비교하면 청킹이 달라도 같은 골든셋으로 잴 수 있다([01-reference-based](../../03-evals/01-retrieval-metrics/01-reference-based.md) 3.2 A 방식).
- 다만 문서 단위 매핑은 "정답 문서의 엉뚱한 부분을 가져와도 정답"으로 본다. 청킹 비교에서는 근거 구간(`evidence_span`)이 청크에 들어 있는지 보는 C 방식이 더 정확하다.
- 검색 지표만으로는 F6(조건 누락)를 못 본다. 생성 쪽 Claim Recall과 Context Sufficiency를 함께 본다.

## 5. 확인할 점

- 청크 수, 평균·최대 토큰 길이, 최대 길이 초과 비율을 설정마다 기록한다.
- 청킹을 바꾸면 sparse 색인과 dense 벡터를 모두 다시 만든다.
